# Auto

A car enthusiast site featuring motorsport news, a daily featured car, technical deep dives, and community builds.

## Wireframe

`index.html` is a dashed-line mock of the layout (open it in any browser).

```
+-----------+---------------------------------------------------+
|   LOGO    |  [ News ] [ Sports ] [ Letter ] [ Explore ]       |
+-----------+---------------------------------------------------+
| Motorsport|  [   CAR OF THE DAY (car artwork, clickable)     ]  |
| News      +---------------------------------------------------+
|           |  [ News headline 1 ]   [ News headline 2 ]        |
|           +---------------------------------------------------+
|           |  UNDER THE HOOD                                   |
| - item    |  Manufacturer | Head Engineer | Engine            |
| - item    |  HP / Torque  | Top Speed     | 0-60              |
| - item    +---------------------------------------------------+
|           |  BUILDS                                           |
|           |  [build card] [build card] [build card]           |
+-----------+---------------------------------------------------+
```

## Sections

- **Logo** — top left.
- **Main navigation** — across the top: News, Sports, Letter (email newsletter sign-up), Explore.
- **Motorsport News** — sidebar under the logo, hugging the left edge.
- **Car of the Day** — full-width button from the news sidebar to the right edge; links to the featured car. Shows artwork of the car: either an original illustration or an AI-generated image (no copyrighted photos).
- **News headlines** — two featured news stories directly under Car of the Day.
- **Under the Hood** — technical specs of the featured car: manufacturer, head engineer, engine specs, horsepower/torque, top speed, etc.
- **Builds** — showcase of builds made by people in the community.

## Status

Layout wireframe only — no styling, real content, or functionality yet.
